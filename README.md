# 스프린트 미션 - 자유게시판 (Next.js)

이전 미션에서 만든 백엔드 API를 활용해 자유게시판을 Next.js로 구현한 프로젝트입니다.

## 🔗 배포 주소

- **웹사이트**: https://one3-sprint-mission-fe-s11u.onrender.com
- **백엔드**: Render로 배포된 백엔드 API 사용
