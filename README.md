## ⚠️ 트러블 슈팅


```markdown

###문제 - 1
input 요소에 focus 스타일을 적용했지만 테두리가 변경되지 않는 문제가 발생했습니다 .

### 원인
css에서 border 속성 값 'solid' 를 'soild' 로 오타 작성하여 브자우저가 스타일을 인식하지 못한 것이 원인이었습니다 .

### 해결
개발자 도구를 통해 해당 요소에 스타일이 적용되지 않는 것을 확인하고,
border 속성 값을 올바르게 수정하여 문제를 해결했습니다.

### 배운 점
단순한 오타라도 스타일 전체가 적용되지 않을 수 있기 때문에,
문제가 발생했을 때 개발자 도구를 활용한 확인 과정이 중요하다는 것을 느꼈습니다. 
```
