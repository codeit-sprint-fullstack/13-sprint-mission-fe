# 🛒 Panda Market Frontend

중고 거래 플랫폼 Panda Market의 프론트엔드 프로젝트입니다.  
React와 Vite를 기반으로 제작되었으며, 상품 조회/등록 기능과 페이지네이션, 태그 입력 기능 등을 구현했습니다.

---

# 🛠️ 기술 스택

## Frontend

- React
- Vite
- React Router
- JavaScript
- CSS

# ✨ 주요 기능

## 상품 목록 조회

- 상품 데이터를 API로 불러옵니다.
- 페이지네이션 기능을 구현했습니다.

---

## 상품 등록

- 상품명
- 상품 소개
- 판매 가격
- 태그 입력

을 통해 상품을 등록할 수 있습니다.

---

## 태그(Chip) 입력 기능

- Enter 입력 시 태그 생성
- 태그 삭제 기능
- 한글 입력 IME 문제 처리

---

## 페이지네이션

- 10개 단위 페이지 처리
- 이전 / 다음 버튼 구현
- 현재 페이지 활성화 스타일 적용
